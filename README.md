# 班级管理工具箱

一组面向个人教学工作的纯前端工具。项目只使用 HTML、CSS 和原生 JavaScript，不需要安装依赖、数据库或后端服务，可直接部署到 GitHub Pages、Cloudflare Pages 等静态托管平台。

Excel 解析库随网站一起托管，名单导入不依赖国外 CDN。移动端拖拽辅助库仍通过固定版本 CDN 加载；加载失败时桌面拖拽和其他功能不受影响。

## 工具

- `classseats.html`：导入学生名单、随机排座、拖拽调整、撤销上一步、小组轮换、镜像视角、保存与恢复座位表。
- `classjournal.html`：按日期记录班级日志，支持搜索、本地备份、TXT 导入导出及 GitHub 私有仓库同步。
- `exceltrans.html`：按指定列匹配两个 Excel 文件，并把文件 B 的数据写入文件 A，同时尽量保留原样式。
- `vote.html`：管理学生名单、题目和投票记录，支持统计展示与 GitHub 私有仓库备份。

## 数据保存方式

浏览器会保存当前草稿和安全快照，GitHub 私有仓库 `Class-Data` 用于跨设备同步。

- 日志、座位和投票在覆盖、导入、清空或恢复前会自动创建本地快照。
- 本地快照保留最近 10 份，只存在当前浏览器和当前网站域名下。
- 清除浏览器网站数据会一并删除本地草稿和快照，因此重要资料仍应定期同步到私有仓库或导出文件。
- GitHub 中的删除操作不会立即抹去 Git 历史。学生姓名、日志和实名投票结果属于敏感数据，请始终使用私有仓库并定期检查访问权限。

所有教学数据以班级为中心存放在 `Class-Data/classes/班级名/`。`roster.json` 是唯一学生名单，包含学号、姓名和性别；`seat.json` 保存该班座位；`votes/` 保存该班历次投票记录。

投票页与座位页选择同一个班级后，会自动读取该班目录中的对应数据，不需要在不同页面重复维护名单。

投票记录当前是实名记录：学生编号、姓名和答案会保存在同一条记录中。如果需要匿名投票，应先调整数据结构后再使用。

## GitHub Token 配置

建议创建 Fine-grained personal access token，并按最小权限配置：

1. Resource owner 选择自己的账号。
2. Repository access 只选择 `Class-Data`。
3. Repository permissions 中仅把 `Contents` 设置为 `Read and write`；`Metadata` 保持默认只读。
4. 设置合理的过期时间，到期后重新生成。

三个云端工具共用同一份 Token。Token 保存在当前设备浏览器中，请勿在公共电脑使用，也不要把 Token 写进代码、截图或 Git 提交。怀疑泄露时应立即在 GitHub 撤销。

投票页面中的管理员密码只是个人设备上的“配置界面锁”，真正决定云端权限的是 GitHub Token。

## 本地预览

直接打开 `index.html` 可以使用大部分功能。为了让页面间跳转、文件读取和安全策略表现与线上一致，建议通过本地静态服务预览，例如：

```powershell
python -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/`。

## Cloudflare 部署

如果 Cloudflare 已经连接当前 GitHub 仓库，通常只需确认以下设置：

- 生产分支：`master`
- 构建命令：留空
- 构建输出目录：仓库根目录（常见填写 `/` 或 `.`）

之后推送到 `master` 会自动触发部署。Cloudflare 控制台中如果显示的是 Workers Builds 而不是 Pages，也应确认它监听的仓库和生产分支。部署前建议先通过修改分支或 Pull Request 检查页面，再合并到 `master`。

## Excel 文件要求

- 排座工具会在前 10 行寻找“姓名”和“性别”列，性别只识别“男”或“女”；如果同时存在“学号”列，会直接与投票名单对应。
- 班级名单必须包含“学号、姓名、性别”表头，座位页和投票页都以这份名单为唯一学生来源。
- Excel 匹配工具只处理 `.xlsx`，会报告匹配行数、未匹配行数和文件 B 中的重复匹配值。

## 项目结构与维护约定

- 保持纯 HTML、CSS 和原生 JavaScript，不引入构建步骤。
- 页面之间的内部引用使用相对路径，保证 Cloudflare 静态部署正常。
- `shared.js` 存放统一学生名单格式、旧数据迁移、路径校验、Token 迁移、公平洗牌和本地备份等共用逻辑。
- 新增工具后，在 `index.html` 的保底配置与排序配置中补充对应信息。
